# تصمیم‌یار بازرگانی آتیه فولاد — نسخه ۱۴

[اجرای آنلاین](https://amirrezasoleimani007.github.io/trade/)

رابط فارسی و RTL برای ارزیابی اقتصاد، نقدینگی، تأمین مالی و شروط انجام معامله. نسخه ۱۴ بازطراحی کامل رابط است و موتور مالی نسخه ۱۳ را حفظ می‌کند.

## اجرا

```sh
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید. فایل‌های لوگو و پوشه فونت برای اجرای محلی لازم‌اند. وابستگی زمان اجرا یا مرحله build وجود ندارد.

## فایل‌های اصلی

- `index.html`: ورودی، اتصال موتور، کنترل قرارداد و تحلیل حساسیت.
- `studio.css` و `studio.js`: سیستم طراحی، ناوبری، نمایش تصمیم و نمودار واکنش‌گرای جریان نقدی.
- `experience.js`: مدیریت سناریو، انتقال JSON، گزارش و تعامل قرارداد.
- `economics-view.js`: پل ارزش و جزئیات اجزای اقتصاد معامله.
- `trade-engine.js`: موتور مرکزی محاسبات؛ در این انتشار تغییر نکرده است.
- `single-sheet-export.js`: اکسل تک‌شیتی با جزئیات و فرمول‌ها.

[شرح تغییرات و اعتبارسنجی](RELEASE-14.md)

## خروجی و ذخیره

گزارش مدیریتی/PDF از چاپ مرورگر استفاده می‌کند. اکسل برای ممیزی فرمول‌ها و فایل JSON برای بازکردن دوباره معامله است. سناریوها در همان مرورگر و دامنه ذخیره می‌شوند و با داده‌های نسخه ۱۳ سازگارند.

## آزمون

```sh
node tests/refinements-121.cjs
node tests/decision-13.cjs
node tests/release-113.cjs /tmp/trade-audit
python tests/formulas-113.py /tmp/trade-audit/formulas.jsonl
```

تست رابط به Playwright و Chromium نیاز دارد:

```sh
APP_CHROMIUM=/path/to/chromium node tests/ui-14.cjs
```

نمونه‌های تصویری مستندات با اعداد فرضی‌اند؛ فرم شروع برنامه بدون معامله نمونه است.
