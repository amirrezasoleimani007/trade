# تصمیم‌یار بازرگانی آتیه فولاد — نسخه ۱۲

نسخه اجرایی این مخزن یک برنامه وب استاتیک و فارسی است. صفحه اصلی از `index.html` بارگذاری می‌شود و مرجع محاسبات مالی `trade-engine.js` است.

## تغییر اصلی نسخه ۱۲

بخش «پول معامله را بچین» بازطراحی شده است:

- خرید: هزینه مالی و کارمزد خرید جدا هستند؛ مبنای کارمزد، زمان پرداخت، VAT داخل اعتبار و وجه بلوکه LC قابل کنترل‌اند و گزینه‌های کم‌استفاده داخل «جزئیات» قرار گرفته‌اند.
- فروش: کارمزد مستقل فروش از UI حذف شده و افزایش قیمت فروش اعتباری مستقیماً روی قیمت نهایی هر بخش می‌نشیند.
- روز وصول فروش = روز تحویل + مهلت وصول.
- فروش نقدی بدون مهلت و بدون افزایش قیمت محاسبه می‌شود.
- Excel تک‌شیتی با همان موتور نسخه ۱۲ ساخته می‌شود.

جزئیات فرمول‌ها، مفروضات و شواهد آزمون در [RELEASE-v12.md](RELEASE-v12.md) و [reports/money-model-v12.json](reports/money-model-v12.json) آمده است.
