# تصمیم‌یار بازرگانی آتیه فولاد — نسخه ۱۳

[اجرای نرم‌افزار](https://amirrezasoleimani007.github.io/trade/) · [تغییرات، راهنمای اجرا و اعتبارسنجی](RELEASE-13.md)

نسخه جاری روی `gh-pages` منتشر می‌شود. برنامه ایستا، فارسی و RTL است و اعداد فارسی نمایش می‌دهد. ورود اطلاعات بر اساس شرایط واقعی قرارداد گروه‌بندی شده و نتایج، اقتصاد معامله، قابلیت اجرا و اقدام پیشنهادی را جدا نشان می‌دهند.

- کارمزد خرید و فروش نقدی، اعتباری و ترکیبی از موتور مرکزی استخراج می‌شود.
- سقف خالی منابع به معنی تأیید ظرفیت نیست.
- پیشنهادهای مذاکره با محاسبه مجدد و ساخت سناریوی قابل مقایسه ارائه می‌شوند.
- سناریوها همراه ورودی‌ها در مرورگر ذخیره و با JSON قابل انتقال‌اند.
- گزارش مدیریتی چاپی/PDF و اکسل تک‌شیت فرمول‌دار در بخش نتایج موجود است.

برای اجرا همه فایل‌ها، لوگو و پوشه `fonts` را نگه دارید و از ریشه پروژه اجرا کنید:

```sh
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید. موتور در `trade-engine.js`، رابط تکمیلی در `experience.js` و اکسل در `single-sheet-export.js` است. مستند نسخه ۱۳ شامل فرمان‌های تست و محدودیت‌های آزمون است. پوشه `legacy` و یادداشت‌های نسخه‌های قبل برای تاریخچه نگه داشته شده‌اند و صفحه اصلی از آن‌ها استفاده نمی‌کند.
