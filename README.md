# تصمیم‌یار بازرگانی آتیه فولاد — نسخه ۱۷

[اجرای نرم‌افزار](https://amirrezasoleimani007.github.io/trade/?v=170) · [تغییرات و آزمون‌ها](RELEASE-17.md) · [نمونه فرضی گزارش کمیته](docs/committee-report-v17-sample.pdf)

سامانه فارسی و راست‌به‌چپ برای بررسی اقتصاد معامله، نقدینگی، ظرفیت ابزارهای خرید، حدود مذاکره و حساسیت تصمیم. موتور مالی نسخه ۱۶٫۱ حفظ شده است؛ نسخه ۱۷ چیدمان، مقایسه و گزارش چاپی را نهایی می‌کند.

## اجرا

فایل `index.html` را باز کنید یا پوشه را روی یک میزبان وب ایستا قرار دهید. فونت، لوگو و اسکریپت‌ها محلی هستند. برای اجرای محلی با سرور:

```bash
python3 -m http.server 8000
```

سپس `http://localhost:8000` را باز کنید. برای ورود، دکمه «ورود به سامانه» را بزنید. ورودی‌های معامله نمونه ندارند؛ نرخ بازده مورد انتظار اولیه ۳۵٪ و قابل تغییر است. تنظیمات ذخیره‌شده شرکت اولویت دارند.

## گزارش قابل چاپ کمیته

۱. اطلاعات قرارداد، روش‌های خرید و فروش، مالیات و سقف منابع را ثبت و محاسبه کنید.
۲. در نتایج، «مشخصات مستند برای چاپ و امضای کمیته» را باز کنید؛ شماره درخواست، جلسه، طرفین، تهیه‌کننده، شرح تحویل و شروط را تکمیل کنید.
۳. «گزارش مدیریتی / PDF» را بزنید. گزارش با اندازه A4 عمودی و حاشیه ۱۲ میلی‌متر آماده می‌شود. در چاپ مرورگر اندازه کاغذ A4، مقیاس ۱۰۰٪ و هدر و فوتر خودکار مرورگر خاموش باشد. برای فایل، مقصد Save as PDF را انتخاب کنید.

گزارش شامل شرایط اصل قرارداد، پیش‌پرداخت/پیش‌دریافت، برنامه پرداخت و وصول، هزینه مالی و کارمزد، مالیات، سود و NPV، حدود قیمت، منابع، جریان نقدی، محل ثبت مصوبه و امضاست. روزها نسبی از شروع معامله‌اند و مبالغ محاسباتی تومان هستند؛ واحد قیمت اولیه جداگانه درج می‌شود. موارد ثبت‌نشده صریحاً مشخص‌اند. تعداد صفحات تابع طول شرایط و تعداد رویدادهاست؛ متن برای تک‌صفحه شدن کوچک نمی‌شود.

شناسه مفروضات برای تطبیق صفحات گزارش است و امضای دیجیتال یا تضمین تغییرناپذیری نیست. تصمیم مدل به‌تنهایی مصوبه کمیته نیست. نمونه PDF داده فرضی دارد.

## ذخیره، بازیابی و مقایسه

«ثبت و مقایسه سناریو» ورودی‌ها، مشخصات چاپی و نتیجه را با هم در همین مرورگر نگه می‌دارد. مقایسه به شکل جدول با معیارهای هم‌ردیف است؛ تفاوت مفروضات زیر جدول قرار دارد. از «سایر عملیات» می‌توان سناریوی مشابه ساخت، مبنا را عوض کرد یا سناریو را حذف کرد. «دریافت فایل معامله» خروجی JSON قابل انتقال می‌سازد. JSONهای نسخه‌های قبلی همچنان پشتیبانی می‌شوند؛ سناریوهای قدیمی را برای محاسبه جاری باز و دوباره ذخیره کنید.

اکسل تک‌شیتی فرمول‌دار شامل ورودی، جزئیات کارمزد، عملیات، رویدادهای نقدی و کنترل تطبیق با موتور است. اگر ورودی تغییر کند، چاپ و ذخیره نتیجه تا محاسبه مجدد غیرفعال می‌شوند.

## فایل‌های اصلی

- `index.html`: فرم‌ها و اتصال رابط به موتور
- `trade-engine.js`: موتور مرکزی مالی، جریان نقدی و تصمیم
- `experience.js` و `entry-workflow.js`: ورود اطلاعات، سناریو و مقایسه
- `studio.js`، `studio.css` و `final-polish.css`: سیستم نمایش و چیدمان فارسی
- `committee-report.js`: گزارش A4 کمیته و صفحه‌بندی
- `economics-view.js`: اقتصاد معامله و تطبیق پل سود
- `single-sheet-export.js`: اکسل تک‌شیتی با فرمول‌های قابل ردیابی
